# Projet-Web 

## Description

Projet-Web is an online forum platform built with PHP. It allows users to create accounts, post discussions, and interact with the community in a web-based forum environment.
###To note 
This project had been realized in the context of an academic project in 2020 and had not been updated since then.
###AI Personal Statement 
No ai have been used in any way during this project.
## Features

- **User Authentication**: Registration and login system
- **Forum Discussions**: Create, read, and participate in forum threads
- **Community Interaction**: Post replies and engage with other users
- **User Profiles**: Manage user accounts and preferences

## Technologies

- **Backend**: PHP
- **Database**: MySQL
- **Frontend**: HTML, CSS, JavaScript
- **Server**: Apache/Nginx 

## Prerequisites

If for any reason you wish to install this, ensure you have the following installed:
- PHP 7.4 or higher
- Web server (Apache/Nginx)
- MySQL or PostgreSQL database


## Installation
1. **Clone the repository**

```bash
git clone https://github.com/Funmilolah/Projet-Web.git
cd Projet-Web
```

2. **Set up the database**
   - Create a new database
   - Import the database schema (if provided in the repo)
   - Update database credentials in the configuration file

3. **Configure the application**
   - Copy `config.example.php` to `config.php` (if applicable)
   - Update database connection details
   - Set any required environment variables

4. **Start the server**

```bash
php -S localhost:8000
```

5. **Access the application**
   - Open your browser and navigate to `http://localhost:8000`
